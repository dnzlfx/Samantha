## Comandos Sam

- `salir` - Guardar y salir
- `limpiar` - Borrar memoria
- `sandbox` - Probar sandbox de código
- `buscar <query>` - Búsqueda web manual
- `\`\`\`` - Modo multi-línea para pegar código

## Auto-Features

**Auto-search**: "busca", "investiga", "qué pasó" → búsqueda automática

**🔍BUSCAR:**: Sam solicita búsquedas cuando no sabe algo

**EXECUTE:**: Sam ejecuta comandos (seguros = automático, peligrosos = confirmación)
